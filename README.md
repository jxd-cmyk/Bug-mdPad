Bug mdPad is a focused Markdown and plain-text editor for Windows. Use it for notes, README files, checklists, project documentation and short guides. Its black-and-white interface combines a text editor with a live preview and an adjustable split view.
## FORMAT WHILE YOU WRITE
Work with headings, bold and italic text, lists, task lists, tables, block quotes and code blocks. Open the Syntax window for a quick reference and insert a snippet at the cursor with a click.
## SAVE, EXPORT AND PRINT
Save Markdown and plain-text files, or export a self-contained HTML document that opens in a browser without an internet connection. Reopen HTML created by Bug mdPad to continue editing the original Markdown embedded in the file. Print the formatted document through the Windows print dialog.
## WORK OFFLINE
No account is required. Editing, preview and HTML export run on your computer. The app contains no advertising or built-in analytics and does not upload your documents to the developer. Web and email links open in your browser or email application when clicked.
## FAMILIAR CONTROLS
Use keyboard shortcuts for opening, saving, printing and editing. Resize the preview to suit your work. Bug mdPad remembers the main window's size and position.
## PLEASE NOTE
Document images are represented by alternative text rather than displayed. HTML reopening supports files exported by Bug mdPad, not general HTML import. For large documents, the live preview shows the first 100,000 characters; saving, HTML export and printing process the full document. Save your changes manually: automatic saving and cloud synchronization are not built in. Exported HTML includes the full Markdown source, so review it before sharing.
